Security and deletion

Bubbles uses scoped Android APIs, explicit system intents, immutable PendingIntents, a protected widget receiver, a non-exported foreground service, and no cleartext or runtime network traffic. You can delete history and folder access inside the app. Android’s Clear storage or Uninstall actions remove application-local data, subject to Android backup restoration.

Important scope

This page describes version 0.5.6 (build 40) and the verified dependency set as of November 11, 2026. If network, analytics, advertising, accounts, or transmitting third-party SDKs are introduced, this disclosure and the Play Console Data Safety form must be updated before release.
